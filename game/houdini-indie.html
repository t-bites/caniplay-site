Minimum Requirements

OSWindows 10+
CPUIntel or AMD x64 CPU with SSE 4.2 required. Houdini will not run on a system with an instruction set lower than SSE 4.2.
GPUA GL4.0 compliant graphics card is required. GL3.3 cards will have missing features and lower GL versions will not run Houdini at all. 12GB VRAM or more is required. Less than this can result in display errors such as blank windows. High DPI displays (4K, 5K) or multiple monitors require a minimum of 12GB. Graphics card must support OpenCL version 1.2.
Memory16 GB RAM
Storage5 GB available space

Recommended Requirements

OSWindows 10+
CPU32 GB or higher and 64GB strongly recommended for fluid simulations
GPUIt is VERY important that you install the latest driver for your graphics card. Failing to do so may result in display issues and/or slow performance
Memory64 GB RAM
Storage8 GB available space
